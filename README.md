# Vishakan S Portfolio

React + Vite portfolio.

## Run locally
```
npm install
npm run dev
```

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com > Add New > Project > import the repo.
3. Vercel auto-detects Vite (Build: `npm run build`, Output: `dist`). Click Deploy.

Or with the CLI: `npm i -g vercel` then `vercel` inside this folder.

## Update content
All text lives in `src/App.jsx`. Replace `src/assets/Vishakan_S_Resume.pdf` and `src/assets/photo.jpg` to change the resume and photo.
